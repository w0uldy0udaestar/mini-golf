# mini-golf

macOS 데스크탑 화면 위에서 플레이하는 사이드뷰 미니골프 **오버레이 게임**.

화면 하단이 코스가 되고, 스틱맨 골퍼가 여러분의 창들 위를 걸어다닙니다. 클럽을 골라
백스윙 높이를 조절하면 공이 실제 탄도 물리(로프트·백스핀·마그누스 양력·Biber 바운스 모델)를
따라 데스크탑을 가로질러 날아갑니다. 마우스는 아래 앱으로 그대로 통과하고, 다른 앱을 쓰는
동안에도 라운드는 화면 아래에서 조용히 흘러갑니다.

> 데모 GIF는 준비 중 — `swift run MiniGolf --demo`로 자동 플레이를 바로 볼 수 있습니다.

## 특징

- **9홀 랜덤 코스**: 홀마다 성격이 다른 다이나믹 지형(능선·분지·플래토·솟은/낮은 그린),
  드라이버 실측 도달 거리를 앵커로 한 전략적 해저드 배치(워터·벙커), 나무·바위 장애물
  (캐노피 밑 펀치샷으로 극복 가능), 좌우 미러 홀
- **클럽 13종** (드라이버~퍼터): 클럽별 로프트·스핀 물리, 상황별 자동 추천(파3 아이언·그린 퍼터)
- **진짜 물리**: 항력·마그누스 양력·스핀 감쇠, 접지 각운동량 보존 바운스(백스핀 백업·릴리스),
  경사 라이(발사각·스피드 반영), 풀파워 미스샷 리스크, 립아웃
- **살아 있는 스틱맨**: 걷기 랜덤 모션 100종, 지형 적응 걸음(경사·러프·벙커), 아주 가끔
  철푸덕 넘어지는 슬랩스틱, 스코어별 감정 반응(만세·주먹·한숨), 조준 방치 시 잔동작
- **조용한 계기판 디자인**: 상자 없는 타이포 HUD, 헤어라인 지형, 포인트 컬러는 깃발 레드 하나
- **합성 사운드**: 외부 샘플 없이 전부 실시간 합성 (클럽별 타구음·바운스·홀인·립아웃)

## 요구 사항

- macOS 13 (Ventura) 이상, Apple Silicon/Intel
- Swift 툴체인 (Xcode 15+ 또는 Swift 5.9+)

별도 접근성 권한은 필요 없습니다 (전역 단축키를 쓰지 않고, 게임 창이 키 윈도일 때만
키보드를 받습니다).

## 빌드·실행

```sh
git clone https://github.com/w0uldy0udaestar/mini-golf.git
cd mini-golf
swift build -c release
.build/release/MiniGolf
```

메뉴바에 ⛳️ 아이콘이 나타나면 실행된 것입니다. 게임 화면은 데스크탑 최하단 띠입니다.

> 서명되지 않은 바이너리라 macOS가 실행을 막으면:
> `xattr -cr .build/release/MiniGolf` 후 다시 실행하세요.

## 조작

| 입력 | 동작 |
|---|---|
| `←` `→` | 클럽 변경 (→ = 드라이버 쪽 = 멀리) |
| `↑` `↓` | 백스윙 높이 (파워) |
| `Space` | 스윙 |
| `R` | 새 라운드 |
| `Esc` | 종료 |
| 메뉴바 ⛳️ 좌클릭 | 재개(키보드 잡기) / 일시정지 토글 |
| 메뉴바 ⛳️ 우클릭 | 메뉴 (사운드·고대비 모드·새 라운드·종료) |

다른 창을 클릭하면 키보드만 놓고 게임은 계속 흐릅니다. 다시 치려면 ⛳️를 누르세요.

**밝은 배경 팁**: 흰 창 위에서는 헤어라인 디자인이 잘 안 보입니다 — 메뉴바 ⛳️ 우클릭 →
**고대비 모드**를 켜세요.

## 데모·디버그 플래그

| 플래그 | 용도 |
|---|---|
| `--demo` | 자동 플레이 (모션 관찰, 사운드 꺼짐) |
| `--seed N` | 코스 시드 고정 |
| `--demo-wall` / `--demo-trip` / `--demo-idle` / `--demo-card` | 벽 스탠스 · 넘어지기 · 아이들 · 스코어카드 관찰 |
| `--no-wall-clamp` | 렌더 경계 클램프 해제 (검증용) |

## 구조

```
Sources/GolfCore/   물리·코스 생성 (UI 무관, 결정론 — 테스트 대상)
Sources/MiniGolf/   앱·렌더 (AppKit + SpriteKit, 스틱맨·HUD·사운드)
Tests/              XCTest 32종 (탄도 불변식·립아웃 경계·코스 통계·회귀)
docs/               리서치 노트·QA 보고서
```

`swift test`로 전체 테스트 실행.
