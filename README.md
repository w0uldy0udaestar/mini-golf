# mini-golf

macOS 데스크탑 화면 위에서 플레이하는 사이드뷰 미니골프 오버레이 게임.

화면 하단이 지면이 되고, 클럽을 골라 스윙 높이를 조절하면 공이 실제 탄도 물리(로프트·백스핀·마그누스 효과)를 따라 데스크탑을 가로질러 날아갑니다. 키보드만으로 플레이합니다.

> 🚧 개발 초기 단계입니다. 계획은 [PLAN.md](PLAN.md) 참고.

## 예정 기능 (MVP)

- 9홀 랜덤 코스 + 타수·파 스코어카드
- 풀 클럽 세트 (Driver ~ Putter 13종) — 클럽별 탄도·백스핀 물리
- 투명 오버레이: 마우스는 아래 앱으로 통과, 라운드 중 키보드로만 조작
- 메뉴바 앱으로 시작/종료

## 스택

Swift / AppKit + SpriteKit(렌더링), 자체 탄도 시뮬레이션 엔진. macOS 전용.
