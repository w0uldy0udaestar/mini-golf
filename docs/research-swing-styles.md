# 선수별 스윙 스타일 실측 (2026-09-15) — 로리 매킬로이·타이거 우즈·브라이슨 디섐보

사용자 제안: "선수별로 스윙 스타일을 선택하면 재밌겠다. 세 명의 드라이버·아이언·웨지·퍼팅 face-on 영상을 키포인트
분석해 적용하자." 결정(2026-09-15): 물리는 동일·연출만, 1단계는 드라이버·아이언 6편, UI에 실명 표기, 차이는 1.3배 과장.
도구·절차는 `refs/video/README.md`, 단일 선수 파이프라인 검증은 `research-swing-keypoints.md`.

## 결론

- 6편 모두 face-on 슬로모션에서 6개 이벤트가 검출됐고 오버레이로 관절 정합을 확인했다. 게임에는
  `SwingKeyframes` 6세트(스타일 × 드라이버/아이언)와 ⛳️ 메뉴 "스윙 스타일"이 들어갔다(웨지는 아이언 세트 공용, 퍼터는 공용).
- 스틱맨에서 읽히는 차이: **힙 드라이브**(임팩트 hipDx 로리 11 > 타이거 8 > 브라이슨 4~8), **피니시 체중 이동**
  (로리 13~14 · 타이거 7~9 · 브라이슨 4~6 — 브라이슨은 제자리에 선 채 끝난다), **척추 기울기**(타이거가 톱·임팩트에서
  가장 크게 타깃 반대로 기움), **톱 손 거리**(브라이슨이 가장 접힘 17~26), **뒤꿈치**(브라이슨 피니시 3~4 vs 로리 7~8).
- 실측 편차를 세 선수 평균 기준 **2.5배**로 과장해 넣었다 (1.3배는 사용자 플레이에서 "뭐가 다른지 모르겠다" 판정 —
  힙 이동 11/8/4px, 톱 손 거리 25/25/17 같은 차이는 70px 스틱맨에서 몇 px라 읽히지 않는다). 템포도 같은 배율로
  과장하고 타이거에는 톱 홀드(0.08s)를 넣었다. 샤프트 각(톱·피니시)은 영상 검출이 불안정해 선수 특징 기반
  수치를 썼고, 템포는 로리만 정상 속도 실측이 있어 타이거는 동일·브라이슨은 빠르게(추정) 잡았다.

## 파이프라인 보강 (이번 6편에서 드러난 문제)

- 손 높이 절대 임계(0.6·몸통)는 작은 골퍼에서 톱을 놓쳐 피니시를 톱으로 오인 → 국소 최대(봉우리) 검출로 교체
- 슬로모션 클립이 톱에서 시작하면 어드레스 없음 → "어드레스→톱이 스윙 길이의 20% 이상"인 스윙만 유효
- 톱 근처 이중 봉우리로 어드레스 탐색 창이 잘림 → 창 시작 = 직전 스윙의 피니시
- 장면 전환·카메라 이동 → 힙 드리프트 ≤ 25px·척추각 ≤ 40° 검사, 인트로 배제용 시간 창 인자
- 가장 느린 유효 스윙에서 포즈, 가장 빠른 스윙에서 템포(정상 속도가 없는 영상은 추정)

## 한계

- 선수당 영상 1편·해상도 불균일(타이거 드라이버 480p). 뒤꿈치는 저해상도에서 잡음이 커서 클램프.
- 어드레스·임팩트 샤프트 각은 검출 실패 → 기존 기하 유지. 템포는 로리 외 추정.
- 2D 투영: 브라이슨의 원플레인·직선 팔 같은 깊이 특징은 손 거리(handD)로만 간접 반영.
- 2단계(웨지·퍼터 6편)는 미착수. 브라이슨 암록 퍼팅은 퍼터 길이 변경이 필요.
- **정면 2D 키포인트가 못 잡는 특징이 진짜 구분점이다**: 타이거의 임팩트 후 클럽 트월·주먹 불끈, 브라이슨의 직선 팔·
  직립·긴 톱 홀드, 로리의 리듬. 키프레임 밖 '트레이드마크 연출'(사용자 선택, 다음 단계)로 넣어야 한다.

## 트레이드마크 연출 (2026-09-15, 2단계 — 키프레임 밖)

사용자 선택: 2.5배 과장과 별개로 "정면 2D 키포인트가 못 잡는 특징"을 연출로 넣는다. 물리는 전부 동일하고
`SwingStyle`의 특성 플래그(`clubTwirl`·`uppercut`·`straightArms`·`armLockPutter`·`impactJump`·`finishRecoil`)로
GameScene의 피니시 홀드·스코어 반응·스윙 경로·렌더에 분기를 둔다. 관찰 플래그 `--demo-trademark`(풀샷마다 굿샷
판정 강제 + `RIG[...]` 30Hz 리그 덤프 → 오프라인 플롯).

### 한계

- 트월·주먹의 '굿샷' 판정은 결과가 아니라 발사 순간 스트라이크 품질(미스힛·파워)로 한다 — 실제 타이거도 공이 뜨자마자
  판단하므로 인과는 맞지만, 굿샷이 러프에 떨어져도 트월은 나온다.
- 암록 손 높이·그립 연장 길이는 실측이 아니라 스틱맨 기하(어깨 66·힙 42)에서 헤드가 공 뒤 6px·지면 2px에 오도록 역산.
- 탭인 홀아웃은 퍼터 스윙 애니메이션(스타일 상한 0.83s)이 끝나기 전에 일어나 스코어 반응이 0.3s 늦게 시작됐다(모든 스타일) →
  스윙 브랜치에서도 반응을 얹도록 수정. 검증은 `--demo-trademark` 리그 덤프 → 프레임 시트(스크래치패드 plot_rig.py)로 했다.
