# 리서치 요약 — 스틱맨 골프 스윙 포즈

작성일: 2026-08-13. Trend Researcher(Opus 4.6) 리서치를 메인 세션에서 검토·적용한 기록. 프로토타입 `POSES` 키프레임의 근거 문서.

## 결론

- **기존 오픈소스 스틱맨 골프 스윙 스프라이트는 존재하지 않는다** (OpenGameArt·GitHub·itch.io 3개 플랫폼 직접 확인, 2026-08-13). 직접 제작이 정답.
- 대신 골프 교습업계 표준인 **P-System(P1~P10) 스윙 시퀀스**가 "이미 만들어진 스틱피겨 포즈 표준" 역할을 한다 (HackMotion, PGA Teaching Manual 계열).
- 게임 적용은 6개 키프레임이면 충분: **P1 어드레스 → P2 테이크어웨이 → P4 톱 → P7 임팩트 → P8 팔로스루 → P10 피니시**. 나머지는 보간.

## 적용한 핵심 원칙

1. **척추 기울기 애니메이션이 최우선** — "몸 고정 + 클럽만 회전"이 부자연스러움의 원인. 척추 측면 틸트(어드레스 -5° → 톱 -18° → 피니시 +25°)가 가장 효과 대비 비용이 낮다.
2. **타이밍 비대칭**: 백스윙 : 다운스윙 : 팔로스루 ≈ 느림 : 매우 빠름(3배) : 감속. 다운스윙 급가속이 스윙 "느낌"의 핵심.
3. **머리는 거의 고정** (시각 앵커), 체중 이동은 **힙 수평 이동**으로 표현 (어드레스 50:50 → 톱 20:80 → 임팩트 80:20 → 피니시 95:5).
4. **단순화 허용**: 사이드뷰에선 양팔을 1~2획으로 합쳐도 됨. 팔 접힘은 어깨→손 거리(handD) 축소로 표현. 무릎 관절 생략 가능(체중은 힙 이동으로). 뒷발꿈치 들림은 임팩트 이후 필수.
5. 톱과 피니시에서 잠깐 멈춤(홀드)이 "멋진 스윙" 인상을 만든다.

## 프로토타입 매핑

- `POSES` 테이블: hipDx(힙 이동) · tilt(척추 틸트) · handA/handD(손 방향·거리) · clubA(샤프트 각) · heel(뒷발꿈치)
- 조준(↑↓) = P1→P2→P4 백스윙 궤적 위 보간 (몸 전체가 움직임)
- Space = 현재 백스윙 포즈 → P7(0.13s, u² 가속, 임팩트에 발사) → P8(0.14s) → P10(0.22s 감속) → 볼 비행 중 피니시 유지
